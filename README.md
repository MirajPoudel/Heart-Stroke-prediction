# Lumbini-Cortex
Lumbini-Cortex is an AI-powered chatbot API designed for students of Lumbini ICT. It works like ChatGPT and allows authenticated students to ask questions, get explanations, and receive help in programming and ICT subjects. The system is built for educational use with restricted access, ensuring only verified students can use the service to support their learning efficiently.
